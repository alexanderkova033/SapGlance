# Russian philosophy pool. Line-for-line with ../philosophy.txt.
#
# READ THIS BEFORE CHANGING A QUOTED LINE. It is the one place in the catalog where translating
# and citing pull against each other, and the resolution is a compromise that has to be stated
# rather than assumed.
#
# WHAT THESE LINES ARE. Every quoted line below is a **Russian rendering of the English edition
# named in its attribution**, made for this app. It is *not* a quotation from a published
# Russian edition, and it does not claim to be. The attribution is deliberately left in English,
# pointing at the same Wikisource or Gutenberg page as the English pool, because that page is
# the text this line was translated from and is therefore the thing a reader can actually check
# it against. Translating the attribution would break that: "Marcus Aurelius, Meditations VIII.4
# (Wikisource)" is a working address, and a Russian gloss of it is not.
#
# WHY IT WAS NOT DONE THE OTHER WAY. The obvious alternative is to use the canonical Russian
# translations, which for most of these authors exist and are better than anything produced
# here: Гаврилов for Marcus Aurelius, Ошеров for Seneca, Ян Хин-шун for Lao Tzu, Топоров for
# the Dhammapada, Айхенвальд for Schopenhauer. Two problems, one practical and one honest. Most
# of them are still in copyright. And where a public-domain Russian edition does exist, citing
# the *English* page beside a *Russian* translator's words would be an attribution that points
# at the wrong text, which is exactly the failure this pool's rules exist to prevent. Naming the
# Russian translator properly means citing the Russian edition, which means a second sources
# file, which the shared-citations design does not have room for. That is the real cost of the
# design, and it is written down here rather than papered over.
#
# So: this is honest as long as it is stated, and it is stated. If a future pass wants genuine
# Russian quotations, the change is structural (per-language sources), not editorial.
#
# WHERE THE ENGLISH IS DELIBERATELY ODD, THE RUSSIAN IS NOT. The Hume line keeps eighteenth-
# century capitals in English because that is how the 1748 edition sets it. Russian has no
# equivalent convention, so the line below is set normally. That is not a silent correction of
# the English; it is the absence of a feature to carry over.
#
# TWO LINES ADDED 2026-08-02 SIT AT A THIRD REMOVE, which is one further than anything else in
# this file and should be said out loud. Ptahhotep reaches a Russian reader as Gunn's 1906
# English of a Middle Egyptian text, rendered again here; the Akan proverb as Rattray's 1916
# English of a Twi saying, rendered again here. Everywhere else the chain is author to English
# edition to this line; in those two it is author to English edition to this line with an extra
# link at the front. The attribution still points at the English page, because that page is
# genuinely what these Russian sentences were made from, which is the whole principle above.
# Russian editions of both exist and are the honest fix, and they need per-language sources.
#
# LENGTH IS THE BINDING CONSTRAINT HERE. Several of these are already at the widget's limit in
# English, and Russian runs longer. Schopenhauer's "the present alone is true and actual" had to
# be rebuilt around a colon to fit. Where a line cannot fit, cut at a punctuation mark the
# original already has, exactly as the English rules allow, and never mid-clause.
