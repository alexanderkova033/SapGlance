# Russian general micro-tips. Line-for-line with ../general.txt and ../general_sources.txt.
#
# THIS FILE IS A TRANSLATION, NOT A POOL OF ITS OWN. The English at ../general.txt is the text
# the citations were checked against and is where the writing rules live: bust a myth, name a
# mechanism, carry a real number, or invert an assumption. Read those rules there. Nothing here
# may say something its English line does not, because the shared ../general_sources.txt is the
# evidence for both and only one of them was checked against it.
#
# LINE ORDER IS LOAD-BEARING. The citations are not translated and there is one copy of them,
# zipped by position against every language. Insert, delete or reorder a line here and the
# catalog fails to load rather than quietly mis-citing, which is the point.
#
# THREE RULES THIS TRANSLATION RUNS UNDER.
#
#   1. NO EM DASH. `TipCatalogTest` forbids it catalog-wide, and Russian reaches for it far more
#      readily than English does, mostly for the missing copula ("сон - это..."). That is a real
#      constraint on the prose rather than a cosmetic one, and it was kept rather than relaxed
#      because working around it pushes every line onto a verb, which is what the plain-English
#      pass was asking for in the first place. Where a line wanted a dash it was restructured,
#      or given a colon.
#   2. NO LONGER THAN THE ENGLISH. Russian runs 10-15% longer than English by default and the
#      widget clips. The card's fitting figure (TipFace.minColumnRatio) was measured against
#      English text, so a translation that lets its lines grow is spending a budget nobody
#      re-measured. Compress instead: drop the article-equivalents Russian does not have, prefer
#      the short synonym, and cut the qualifier the English only had for rhythm.
#   3. THE HEDGE IS NOT DECORATION. "Is linked to" is "связано с", never "вызывает"; "can help"
#      is "может", never a bare present tense. Russian makes the causal reading easy to slip
#      into, and a hedge lost in translation is the same error as a hedge dropped in English,
#      just harder to spot.
#   4. NO SECOND-PERSON PAST TENSE, added 2026-08-03 and the rule with the widest reach. Russian
#      past tense carries the subject's gender, so "если долго печатал" tells a woman the app
#      assumes she is a man. It is a correctness bug rather than a style note, it was spread
#      across every pool, and the fix is never to guess: use the present ("если печатаешь уже
#      давно"), an impersonal form, a noun, or give the sentence a different subject entirely.
#      That last one is the most useful and is worth learning: "Когда ты последний раз пил?"
#      cannot be repaired in place, so the drink becomes the subject instead, "Когда вообще был
#      последний глоток воды?". `ru/motivation.txt`'s header works the same rule through a pool
#      where nearly every line is addressed to the reader.
#
# THE 2026-08-03 PASS, and what it found. A native reader's verdict was that the whole catalog
# read as unintentionally funny. The practical pools turned out to need surgery rather than
# rewriting — they carry numbers and mechanisms, so there is less idiom to mangle — and the
# faults clustered into four kinds worth naming, because each will recur:
#
#   Gendered past tense    Rule 4 above. `general`, `afternoon` and `wellbeing` all had one.
#   Calqued idiom          "Uncross your legs" was "Расставь ноги", which means the opposite of
#                          uncrossing them and is funnier than the tip deserves.
#   False friends of jargon  "пикует" for "peaks" (пикировать is what a plane does), "ядро тела"
#                          for "core temperature", "устойчивость к инсулину" where the term is
#                          инсулинорезистентность.
#   Calqued abstractions   "менее реактивно", "плоское настроение", "хорошую вещь". Each is a
#                          dictionary-correct word doing a job Russian gives to another one.
